Frequently Asked Questions

সাধারণ প্রশ্ন

RJ NETWORK-এর service, speed, router ও support নিয়ে সাধারণ তথ্য।

Internet slow হলে কী করব?

Router restart করুন, অন্য device-এ speed পরীক্ষা করুন। সমস্যা থাকলে Support form থেকে সার্ভিস সমস্যা জানান।

Router login address কী?

Router brand/model অনুযায়ী আলাদা হতে পারে। Router Help page দেখুন।

WiFi password ভুলে গেলে?

Router admin panel থেকে WiFi settings পরিবর্তন করা যায়। Admin password না জানলে support নিন।

প্যাকেজ পরিবর্তন করতে চাই।

Support page-এ প্যাকেজ পরিবর্তন নির্বাচন করে customer ID ও package দিন।

নতুন সংযোগ নিতে কী করতে হবে?

Support page থেকে নতুন সংযোগ নির্বাচন করে নাম, মোবাইল, ঠিকানা ও package তথ্য পাঠান।
